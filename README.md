# MarkdownEditor

Простой редактор маркдауна с рендером

## Возможности рендеринга

* Заголовки
* Списки (маркированные, нумерованные, вложенные)
* Таблицы
* Код-блоки, инлайн коды
* Гиперссылки, картинки
* Подчеркивания и другие мелочи

## Системные требования

* Минимальная система - Windows XP (x86 либо x64)
* .NET Framework 3.5
